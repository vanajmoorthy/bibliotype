{# Floating 3D book piles behind the page content. Used on the home and 404 pages. #}
{% comment %} Pseudo-3D isometric books: closed six-face boxes (cover / back / spine / fore-edge / head / tail), one --book-color per book, all lying flat. Each .ambient-pile wrapper owns the position (--x), drift (--d/--delay), screen tilt (--r), scale (--s) and the pile's shared opacity, so books composite at full strength and the pile fades as one unit. Books inside carry only --tk (thickness), --yo (resting lift: running sum of the projected thicknesses below, ~9.3px x --s x --tk per book) and --rz (stacked-by-hand jitter). --s varies per pile (0.5-0.7) so stacks differ in size; --py is the mean of the pile's --yo lifts, used to centre the --r pivot on the pile's visual middle. Bottom book first in DOM so the top of the pile paints in front. See .ambient-pile / .ambient-book in static/src/input.css. {% endcomment %} {# pile of 3 #}
