{% comment %} Podium Bars Partial — vertical bar comparison, an alternative to the horizontal number line. Two or three chunky coloured bars with the value on top and the tag underneath the baseline. Bar heights use the same min/max window as the number line (not a zero baseline) so small differences stay readable; the scale note below keeps that honest. Bars animate up on first scroll into view. Required: pb_min, pb_max — numeric window for the scale pb_user_value/tag — user bar pb_comp_value/tag — comparison bar Optional: pb_user_color / pb_comp_color / pb_third_color — Tailwind bg classes pb_third_value/tag — optional third bar pb_decimals — decimal places (default 0) pb_scale_note — small print under the chart (e.g. "scale: 300–400 pages") {% endcomment %} {# djlint:off #}
