# Handoff: Bibliotype logo — 3-book stack + DNA helix mark

## Goal

Replace the 🧬 emoji with a proper logo mark: a small isometric stack of three books
with a DNA double helix woven in, in the site's neobrutalist 8-bit style. Generate
candidates with Gemini image gen, iterate with the user, then wire the winner in.

- Line ~203: navbar `🧬<span>Bibliotype</span>` — replace the emoji with an inline

## Generator script (ready to run)

`.testing-screenshots/gen_logos.py` — stdlib-only script that hits the Gemini REST
API directly and generates all four variants in one run. **`.testing-screenshots/` is
untracked scratch** — if it's gone, the full image-gen prompt is in
`docs/handoffs/2026-08-24-ambient-iso-books.md` (item 7) and the script is trivial to
recreate from it.

Run it inside the web container (which has `GEMINI_API_KEY`; a Claude Code permission
rule blocks reading `.env` directly, so don't try):

```bash
docker-compose -f docker-compose.local.yml exec -T web python /app/.testing-screenshots/gen_logos.py
```

Outputs land in `.testing-screenshots/logo-{a-ribbon,b-page-lines,c-standing-helix,d-minimal}.{png,jpg}`.

## The four variants

(a) helix as a bookmark ribbon winding through the stack; (b) helix formed from the
books' own fore-edge page lines; (c) helix standing beside/behind the stack;
(d) minimal mark — two intertwined ribbons hinting at a book cover. Palette and full
prompt text: ambient-iso-books handoff item 7. Mark only, no wordmark, must stay
legible at 32×32.

## Process

1. Run the generator (all four variants), send the images to the user.
2. Iterate on the favourite with Gemini's image-editing mode (pass the image back
   with edit instructions) until the user is happy.
3. Wire in: navbar inline asset + regenerate the three favicon files (32/16/ico) from
   the final mark; drop the data-URI emoji favicon line.
4. Static files: new PNGs go in `static/`, referenced via `{% static %}`. Run
   collectstatic implications are handled by deploy; locally just hard-refresh.
